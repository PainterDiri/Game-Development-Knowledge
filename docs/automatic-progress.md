# 自动续学与多人独立使用

## 不需要手工维护进度表

网站会在浏览课程页面时自动保存：

- 最后阅读的课程页面；
- 最靠近当前位置的章节标题；
- 页面内滚动位置。

下次打开网站首页时，会自动返回上次位置。首页短暂显示“继续上次学习”区域，可以：

- 立即继续；
- 本次留在首页（下次打开仍会自动续学）；
- 清除本浏览器的记录。

这不需要账号、打勾、填写 `progress.md`，也不会修改仓库。

## 每个人天然独立

进度保存在浏览器的 `localStorage` 中，而不是公开仓库：

- 不同人的浏览器互不影响；
- 分享同一个网站不会分享个人进度；
- GitHub Pages 不会收到作答、滚动位置或学习记录；
- 清理浏览器网站数据、使用无痕窗口或更换设备后，记录不会自动迁移。

如果多人共用同一浏览器账户和同一个浏览器配置文件，网站会视为同一个学习者。需要隔离时，使用不同浏览器配置文件即可。

## 做题不要求建错题本

推荐最省事的流程：

1. 看到题目后先在心里组织答案，必要时拿纸写关键词；
2. 卡住时只展开“最小提示”；
3. 再展开完整答案，对照机制、边界和验证方式；
4. 如果答错，立刻用自己的话重新说一遍，然后继续学习。

只有反复犯同一个错误，或者需要调试代码时，才值得临时记一条。仓库不再强制维护作答日志、错题本或架构决策日志。

## 实践代码放在哪里

网站只提供实验题面、验收标准和折叠参考解法。个人代码可以直接放在你习惯的位置。

如果希望把实践放在本仓库旁边，推荐按需创建：

```text
.practice/<course-slug>/
```

`.practice/` 已被 Git 忽略，不需要提前为 24 门课程创建空目录。只有真正开始某个实验时再建即可。
