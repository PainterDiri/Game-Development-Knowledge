# 课程知识集质量门禁

## 自动门禁

- 目录符合 `course-folder-template.md`，课程索引中有对应条目；
- 内部 Markdown 链接有效；
- 每门课存在 `questions.md`、`answers.md`、`rubric.md` 和 `labs/solutions.md`；
- 题目与答案 ID 一一对应，答案和实践解法使用 `<details>`；
- 公开目录不存在个人进度、作答、错题、决策日志或个人工作区；
- 无明显密钥、私人绝对路径和私密数据；
- `sync_docs.py`、`check_repo.py`、`git diff --check` 与 MkDocs 严格构建通过。

## 人工门禁

### 正确性

- 关键概念有定义、机制、不变量、边界和反例；
- 代码能运行或明确标注伪代码；
- 复杂度、线程安全、内存所有权和网络信任边界没有偷换概念；
- 引擎 API 与记录版本匹配。

### 教学有效性

- 章节从问题出发，不是目录堆砌；
- 实践少而精且能复现；
- 题目能区分“看过”与“理解”；
- 每题有最小提示、完整推理、边界、验证方式和常见错误；
- 每个实践有参考路线、验收证据、替代方案和故障诊断；
- 不要求为了形式填写进度表、作答日志、错题本、决策日志或实验报告。

### 游戏相关性

- 至少一个案例落到游戏运行时、工具、服务端或生产；
- 说明专业团队遇到的规模问题和教学简化边界；
- 肉鸽课程覆盖种子、组合、冲突、存档或内容管线中的至少两项；
- 网络课程覆盖权威性、延迟、复制/预测/插值中的至少两项。

### 多人独立与自动续学

- 阅读位置只由浏览器 `localStorage` 自动保存，不写入仓库；
- 不同浏览器访问同一网站时彼此独立；
- 首页可继续、暂停或清除上次阅读位置；
- `completed` 只表示公开课程生成完成，不表示学习者完成。

### 公共发布

- 无个人信息、账号、密钥、机器绝对路径；
- 代码和资产许可证可说明；
- 不复制受版权保护的长文本或商业项目私有资料；
- Pages 产物不包含 `.practice/`、缓存或本地构建输出。
