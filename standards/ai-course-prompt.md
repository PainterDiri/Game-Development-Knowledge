# AI 课程生成提示

```text
请为本仓库生成下一门课程知识集，并严格只处理这一门课。

执行前：
1. 阅读 AGENTS.md、roadmap/README.md、roadmap/course-index.json 与相关 standards；
2. 检查课程状态、前置课程出口、深度、实践接口和游戏映射；
3. 研究官方文档/标准/论文/源码/大学教材，记录版本、访问日期、用途、限制与冲突；
4. 先设计课程专属心智模型，并把课程首页 README.md 写成“课程定位 + 课程地图 + 学习入口”；不要强制创建 00-course-map.md。

正文要求：
- 课程正文是最重要的交付，不得只有提纲、清单、实践或 API 摘要；
- 每个核心知识块都要有问题场景、定义/边界、机制/不变量、详细示例或代码、失败/取舍、游戏映射、验证和延伸；
- 术语首次出现时就地解释中文、英文、缩写和边界；术语表非默认入口；
- 章节数量和结构由课程难点决定，合并过小页面，避免重复目录和长前言；
- 图示、Mermaid、代码和交互只在降低理解成本时使用，图示必须有文字结论；
- 最多 1 个主实践 + 2 个微实验，不为凑数创建实验；默认将题面、提示、解法、验收和代码入口合并到 practice.md；
- 默认将题目与折叠答案放在同一 assessments.md；题目少而精、可判定、可验证、能迁移，删除纯主观题；
- 每道题必须有最小提示、完整答案、推理、边界、常见错误、验证方法和游戏映射；
- 代码说明语言/版本、运行命令、预期结果和已知限制；不提交缓存、构建输出、个人状态或私人路径。

生成后：
1. 更新课程状态和公开索引；
2. 运行 python3 scripts/sync_docs.py、python3 scripts/check_repo.py、git diff --check 与 MkDocs 严格构建；
3. 按 quality-gates.md 人工检查正文深度、正确性、可复现性、视觉可读性、版权和隐私；
4. 用户已授权且远程可用时 commit 并 push，不使用 --force，并验证部署结果。
```
