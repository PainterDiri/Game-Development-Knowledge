# AI 课程生成提示

```text
请为本仓库生成下一门课程知识集。

执行前：
1. 阅读 AGENTS.md、roadmap/README.md、roadmap/course-index.json 与相关 standards；
2. 确认课程状态、前置、深度、实践接口和游戏映射；
3. 研究当前可靠来源，记录版本、访问日期、用途、限制与冲突；
4. 先完成课程地图，并说明为什么采用这种课程专属结构。不要批量套固定章节模板。

内容要求：
- 每个核心概念必须有定义/边界、机制/不变量、取舍/失败、游戏映射和验证证据；
- 数学、算法、系统、架构、引擎和生产课程采用各自合适的推导与验证方式；
- 术语首次出现时解释中文、英文、缩写和边界；
- 图示只用于复杂关系，优先 Mermaid 或可再生成可视化，并提供文字结论；
- 实践数量按价值决定，最多一个主实践和两个微实验；
- 题目数量按知识密度决定，优先高信息量问题，不按章节凑数；
- 题目与折叠答案一一对应，解析必须包含推理、边界、错误、验证和游戏迁移；
- 不写长前言、鸡汤、API 清单、重复目录或只有结论的题解；
- 不要求学习者打勾、写日志、错题本、决策记录或实验报告。

生成后：
1. 更新课程状态和公开索引；
2. 运行 python3 scripts/sync_docs.py、python3 scripts/check_repo.py、git diff --check 与 MkDocs 严格构建；
3. 按 quality-gates.md 人工检查课程专属性、正确性、可复现性、视觉可读性、版权和隐私；
4. 用户已授权且远程可用时 commit 并 push，不使用 --force。
```
