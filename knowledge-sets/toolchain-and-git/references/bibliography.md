# 参考书目

- [Git Book](https://git-scm.com/book/en/v2/) — Git 官方，持续维护，访问日期：2026-08-22。用途：Git 对象、分支、合并与协作基础。
- [git-fsck](https://git-scm.com/docs/git-fsck) — Git 官方文档，访问日期：2026-08-22。用途：仓库对象可达性与完整性检查。
- [git-bisect](https://git-scm.com/docs/git-bisect) — Git 官方文档，访问日期：2026-08-22。用途：回归二分与自动判定边界。
- [Git LFS](https://git-lfs.com/) — Git LFS 官方，访问日期：2026-08-22。用途：大文件指针与存储边界。
- [About Git Large File Storage](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-git-large-file-storage) — GitHub，访问日期：2026-08-22。用途：LFS 使用与限制。
- [Reproducible Builds: Definition](https://reproducible-builds.org/docs/definition/) — Reproducible Builds，访问日期：2026-08-22。用途：可复现构建定义和差异层次。
- [Workflow syntax for GitHub Actions](https://docs.github.com/en/actions/writing-workflows/workflow-syntax-for-github-actions) — GitHub，访问日期：2026-08-22。用途：事件、job、step、权限和矩阵概念。
- [Store and share data with workflow artifacts](https://docs.github.com/en/actions/using-workflows/storing-workflow-data-as-artifacts) — GitHub，访问日期：2026-08-22。用途：缓存与 artifact 的交付边界。
- [Security hardening for GitHub Actions](https://docs.github.com/en/actions/security-for-github-actions/security-guides/security-hardening-for-github-actions) — GitHub，访问日期：2026-08-22。用途：最小权限、第三方 action、秘密与不可信输入。
- [Asset Metadata](https://docs.unity3d.com/Manual/AssetMetadata.html) — Unity Manual，访问日期：2026-08-22。用途：资产元数据、引用和版本控制边界。
- [Version control integration](https://docs.unity3d.com/Manual/VersionControlIntegration.html) — Unity Manual，访问日期：2026-08-22。用途：Unity 工程版本控制原则。
- [Unity Editor command line arguments](https://docs.unity3d.com/Manual/EditorCommandLineArguments.html) — Unity Manual，访问日期：2026-08-22。用途：batch/headless 自动化边界。
- [Source Control in Unreal Engine](https://dev.epicgames.com/documentation/en-us/unreal-engine/source-control-in-unreal-engine) — Epic Games，访问日期：2026-08-22。用途：UE 源代码控制集成。
- [Automation System in Unreal Engine](https://dev.epicgames.com/documentation/en-us/unreal-engine/automation-system-in-unreal-engine) — Epic Games，访问日期：2026-08-22。用途：UE 自动化测试入口。
- [Command-Line Arguments in Unreal Engine](https://dev.epicgames.com/documentation/en-us/unreal-engine/command-line-arguments-in-unreal-engine) — Epic Games，访问日期：2026-08-22。用途：UE 无交互命令边界。

> 版本说明：引擎与 GitHub Actions 页面会随版本更新。课程正文只依赖跨版本原则；具体项目必须锁定 Editor/Engine、包、平台 SDK、action 和 runner 版本后再复核命令。
