# 自评量规

| 维度 | 达标 | 需要补强 |
|---|---|---|
| 边界 | 能把源、元数据、缓存、产物、证据分类并说明验证方式 | 只背目录名，无法解释删缓存/冷构建 |
| Git | 能解释快照、引用、共享历史回退和冲突边界 | 把 Git 当同步盘，默认 reset/强推 |
| 复现 | 能列出工具、依赖、seed、配置、平台等输入，并比较两次结果 | 只说“锁版本”但不记录命令和证据 |
| 调试 | 能写最小复现并用稳定测试/二分定位 | 只收集截图或重复运行 |
| CI/发布 | 能区分 cache/artifact、门禁、权限和回滚 | 只追求绿色，不保留产物或日志 |
| 游戏迁移 | 能把原则映射到 Unity、UE 和肉鸽 seed/内容版本 | 变成 API 清单，忽略生命周期和失败路径 |
