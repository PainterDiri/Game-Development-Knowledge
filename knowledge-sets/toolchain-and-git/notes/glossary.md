# 术语表

- **工具链（toolchain）**：从源输入到测试、构建、发布和诊断证据的一组工具与命令。
- **可复现构建（reproducible build）**：在相同且已声明的输入下重建等价输出；不自动保证正确。
- **源（source）**：人或生成器维护、需要审查的工程输入。
- **缓存（cache）**：可删除后重新生成、用于加速的中间数据。
- **产物（artifact）**：构建或测试输出，如包、可执行文件、符号、报告。
- **manifest**：描述构建 ID、提交、工具、配置、依赖和输入的机器可读清单。
- **快照（snapshot）**：Git 提交记录的项目文件状态，不是逐行差异的永久存储。
- **引用（ref）**：指向 Git 对象的可移动或固定名称，如分支、标签。
- **回归（regression）**：原本通过的行为因新变化而失效。
- **CI**：Continuous Integration，持续集成；自动执行可重复检查的流程。
- **LFS**：Large File Storage，把大文件内容与 Git 指针分离的扩展。
- **Headless/Batch**：无交互界面运行工具，适合自动化但需要显式处理许可证、输入和日志。
