# 课程知识集

每门课程对应一个公开目录，顺序和元数据见 [`roadmap/course-index.json`](../roadmap/course-index.json)。

## 最省事的学习方式

课程正文、实验题面、题目、答案解析和评分标准全部属于公开知识库。阅读网站时，浏览器会自动保存最后访问的课程页面、章节和滚动位置；下次打开首页即可继续，不需要手工勾选进度或维护学习档案。

做题时先在心里回答，必要时只在纸上写关键词，然后展开折叠提示或答案核对。仓库不要求建立作答日志、错题本或架构决策日志。

实践代码可以放在任意方便的位置。如果希望与仓库放在一起，可在真正开始实验时按需创建：

```text
.practice/<course-slug>/
```

`.practice/` 已被 Git 忽略，不会污染公开内容，也不需要提前创建空目录。每个访问者的网页阅读位置保存在各自浏览器的 `localStorage` 中，不会上传或互相覆盖。

## 课程状态

- `scaffolded`：目录已创建，等待知识生成；
- `in-progress`：公开课程正在研究或生成；
- `completed`：公开正文、实践、答案解析、引用和校验均已完成。

这些状态只描述公开课程材料是否完成，不追踪任何人的个人学习进度。
