# 课程知识集源文件

每个一级文件夹对应一门课程。`planned/scaffolded` 课程只保留最小骨架；研究完成后，课程地图会决定真正需要的章节、图示、代码、题目和实践文件。

- [课程顺序与状态](../roadmap/course-index.md)
- [内容质量规范](../standards/knowledge-generation-spec.md)
- [文件职责与可变结构](../standards/course-folder-template.md)

这里不存放任何学习者的进度、作答或个人练习。

## 目前哪些内容真正可学

截至 **2026-08-23**，只有[工具链与 Git](toolchain-and-git/README.md)已经具备完整正文、实践、评估、研究记录和可下载实践代码。其他目录是公开课程骨架或研究入口，不应被当作完整教材。

- [知识集现状审计与优化方案](../roadmap/knowledge-set-audit.md)：解释核心主线、支撑课程、方向拓展和建设优先级；
- `scaffolded`：只有课程定位和生成入口；
- `in-progress`：正在建设，未完成页面不伪装成完整课程；
- `completed`：正文、题目/解析、实践、来源、接缝和质量门禁均已完成。
