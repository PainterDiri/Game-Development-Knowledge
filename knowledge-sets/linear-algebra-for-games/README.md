这门课不把向量和矩阵当成需要背诵的公式表，而是从“角色如何移动、相机如何看见世界、模型如何把输入变成输出”逐步建立线性代数。后续机器学习课程会复用同一套语言：向量是表示，矩阵是线性变换/参数，点积是相似度或加权组合。

## 前置与补桥

需要基础代数和终端操作。若不熟悉坐标轴，先做一个 2D 网格补桥：在纸上标出原点、正方向、点 `(2, 1)` 和位移 `(−1, 3)`，再用 Python 打印结果。

## 课程地图

```text
坐标与位移
→ 向量运算与几何意义
→ 线性组合、基与维度
→ 矩阵作为变换
→ 坐标系与换基
→ 旋转、缩放、反射与复合
→ 2D/3D 相机与投影
→ 数值误差与稳定实现
→ 游戏空间中的碰撞/瞄准/动画
→ 向量表示、点积和矩阵在 AI 中的用途
```

D3 目标是 12–18 个连续知识单元，核心单元要有推导、可视化实验、反例和代码；不要用一页“公式速查表”代替课程。

## 可验证出口

独立推导并实现一组 2D/3D 变换实验，能从坐标图和数值输出解释移动、旋转、相机与投影的结果；同时能说明 embedding、线性层、相似度搜索为何需要向量和矩阵，但不把“懂矩阵乘法”冒充为懂机器学习。
