> **定位**：这不是“调用一个模型”的工具课，而是把线性代数、概率、优化和程序实现连接成机器学习的完整数据流。

## 前置与补桥

建议先完成 C、线性代数、微积分与概率、数据结构。若不会矩阵乘法或函数，可以先做一个补桥实验：用 Python 只实现 `y = wx + b`、均方误差和一次手算梯度更新，并解释每个符号的输入/输出。

## 课程地图

```text
游戏数据与任务
→ 训练/验证/测试
→ 线性模型与基线
→ 损失、梯度与优化
→ 多层网络与反向传播
→ 泛化、过拟合与指标
→ 推理成本、数据漂移与游戏接缝
```

每个阶段都要有代码、指标和失败案例；不能只展示训练曲线而不解释基线和测试集。

## 可验证出口

实现一个小型玩家行为或敌人分类/回归模型：有明确数据字典、可复现切分、非机器学习基线、训练日志、测试指标、错误样本和“为什么在某些游戏问题上不使用 ML”的边界说明。

后续 [LLM 与 Transformer](../llm-and-transformers/README.md) 会在本课程的表示、损失、梯度和评估基础上进入序列模型；[生成式 AI 与游戏工具工程](../generative-ai-for-games/README.md) 会把模型接入工具生命周期。
