> **核心问题**：一段游戏规则怎样从“看起来能跑”变成可以解释对象、类型、内存、生命周期、错误路径和测试证据的 C 程序？

旧版课程把 18 个主题各压成很短的摘要，术语、代码和验证都不足，学习者只能“看过”，不能像真正上课一样推演、运行、失败和修复。本版重新按概念依赖组织：每章先解决一个可观察问题，逐步建立模型，章末立刻练习；最后完成一个可运行的命令行房间战斗模拟器。

## 适合谁与前置诊断

默认面对第一次系统学习编程的人。需要会在终端中定位目录、运行命令、阅读退出码，并知道 Git 主仓库与个人练习副本的区别。先在任意临时目录完成：

```bash
printf '#include <stdio.h>\nint main(void){ puts("ready"); return 0; }\n' > hello.c
cc -std=c17 -Wall -Wextra -pedantic hello.c -o hello
./hello
printf 'exit=%s\n' "$?"
```

如果不能解释“源文件 → 编译/链接 → 可执行文件 → 进程 → 退出码”，先学第 1 章即可，不必先懂指针。课程以 C17 为共同基线；C23 新特性作为后续查阅，不影响核心机制。

## 章节地图

| 章 | 核心问题 | 前置输入 → 本章产出 | 完成证据 | 下一章用途 |
|---:|---|---|---|---|
| 1 | `.c` 为什么不能直接运行 | 文件/终端 → 翻译阶段、I/O、参数、退出码 | 能解释一次完整构建与失败阶段 | 值必须由类型和对象承载 |
| 2 | 变量到底保存了什么 | 进程 → 对象、值、类型、初始化、格式化输出 | 编译警告与值/地址观察 | 表达式会组合不同类型 |
| 3 | 同一公式为什么会算错 | 类型 → 运算顺序、转换、整数/浮点边界 | 边界表和无警告构建 | 条件与循环依赖表达式 |
| 4 | 循环何时正确并终止 | 表达式 → 分支、循环、不变量、状态机 | 能证明 `[0,count)` 访问 | 复杂流程需要函数边界 |
| 5 | 函数如何隔离状态 | 控制流 → 参数、返回值、作用域、栈、递归 | 调试器/打印调用轨迹 | 大程序需要多文件组织 |
| 6 | 声明、定义、链接有何区别 | 函数 → 头文件、翻译单元、链接、Make | 分别复现编译/链接错误 | API 将传递数组和缓冲区 |
| 7 | 数组为何越界 | 类型/函数 → 连续内存、长度、搜索/排序 | ASan 报告与边界测试 | 字符串是带约定的字节数组 |
| 8 | 文本输入为何容易出错 | 数组 → `char`、终止符、`fgets`、解析 | 拒绝截断/非法输入 | 指针解释地址和缓冲区 |
| 9 | 指针怎样安全地间接访问 | 对象/数组 → 地址、解引用、`const`、别名 | 画出对象/指针/有效期 | 复合游戏状态需要数据建模 |
| 10 | 如何表达敌人和状态 | 指针 → `struct`、`enum`、union、bit flags | 状态不变量和布局观察 | 可变规模需要明确所有权 |
| 11 | 谁分配、谁释放、何时失效 | 生命周期 → `malloc/free/realloc`、所有权 | 无泄漏、无 UAF、失败安全 | 持久化需要 I/O 与格式边界 |
| 12 | 存档失败如何显式处理 | 数据模型 →流、文本/二进制、schema、错误 | 损坏/截断 fixture 测试 | 工具帮助发现语言级错误 |
| 13 | 为什么“偶尔不崩”仍然错误 | 全部前置 → 预处理、UB、警告、Sanitizer、调试器 | 从报告定位并修复缺陷 | 最终需要系统化测试与模块化 |
| 14 | 如何把知识组合成组件 | 全部前置 → 测试分层、API 契约、性能证据 | `make test`、`make asan`、CLI 冒烟 | 进入主实践 |

1–14 章均为必修。函数指针、高级宏、ABI、并发和手写分配器只做边界提示，分别在后续语言、系统和引擎课程深入。

## 学习方式

每章建议按“读问题 → 手抄/运行最小程序 → 制造一次失败 → 做章末练习 → 合上答案复述”完成。章末练习就在当前页面，不再另设集中练习题章节。

## 学完后的出口

你应能：

1. 区分编译、链接和运行时错误，阅读警告、退出码与 Sanitizer 报告；
2. 用对象、类型、值、地址、生命周期和有效区间解释 C 程序；
3. 设计带长度、`const`、错误码、输出参数和失败原子性的 API；
4. 选择固定容量或动态内存，并列出所有权、失效和失败路径；
5. 用结构体、枚举、位标志和版本化序列化表达游戏状态；
6. 用多文件、头文件、Makefile、测试与调试工具交付一个可复现 C17 小项目。

> 资料基线：ISO/IEC 9899 的公开 C11 草案 N1570 用于语言对象、表达式、数组、指针、库与未定义行为的基础语义；GCC 与 Clang 官方文档用于警告和 Sanitizer。版本敏感开关以本课程生成日 **2026-09-01** 的官方文档为准。
