默认面对第一次系统学编程的人：先从“程序如何读输入、保存状态、调用函数并输出结果”开始，再逐步进入数组、指针、内存布局、生命周期、调试和小型库设计。

## 课程地图

```text
编译/运行与基本类型 → 表达式/分支/循环 → 函数与模块
→ 数组/字符串 → 指针与地址 → 结构体与数据布局
→ 动态内存与所有权 → 文件/错误/调试 → 数据结构组件
→ 测试、性能与 C/C++/C# 接缝
```

D3 目标是 12–18 个连续知识单元，每个核心难点都要有最小程序、逐行解释、故意错误、调试命令和游戏映射；内存和指针不能压缩成一章名词介绍。

## 可验证出口

实现并验证一个内存边界清晰、错误路径明确、可调试的小型运行时组件库，并能解释它如何导出给 Unity/UE 或被后续数据结构课程复用。
