> **定位**：把生成式 AI 当成一个需要数据、权限、评估、缓存、人工审核和回退的工程系统，而不是一个“输入提示词就完成”的按钮。

## 前置与补桥

需要 LLM/Transformer 基础、资源管线和软件工程。补桥任务：为一个 NPC 对话工具写出输入数据、允许调用的工具、输出 schema、人工审核点和失败回退，不先接模型。

## 课程地图

```text
应用边界与验收
→ 数据许可、版本和提示
→ 检索与工具调用
→ 文本/图像/音频生成管线
→ 质量、事实性和风格评估
→ 缓存、延迟、成本与端侧部署
→ 提示注入、隐私和安全
→ Unity 编辑器工具/内容接缝
→ 发布、监控和回滚
```

## 可验证出口

交付一个独立可运行的游戏开发 AI 工具原型：带固定评估集、输入/模型版本、许可记录、人工审核、缓存键、失败回退、日志和主项目适配器。正文必须同时展示一次“模型有效”和一次“模型不应被采用”的证据。
