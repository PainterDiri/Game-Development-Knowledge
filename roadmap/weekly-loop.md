# 单次学习闭环

“周计划”容易变成形式负担，因此默认按一次 45–90 分钟的闭环组织：

```mermaid
flowchart LR
    A[选择一个问题] --> B[理解机制与边界]
    B --> C[心答 / 纸答]
    C --> D[运行最小验证]
    D --> E[核对解析与失败原因]
    E --> F[脱离材料重新解释]
```

## 标准版

- **理解 25–45 分钟**：只处理一个可验证主题；
- **题目或实验 10–30 分钟**：先独立完成，卡住再看最小提示；
- **复述 5 分钟**：说清结论、机制、边界和游戏映射。

## 时间很少时

只完成“一个概念 + 一个验证”。不要为了保持连续天数而快速扫过多个章节。

## 需要深入时

若同一错误反复出现，或它会影响主项目调试，再自行记录最小复现和修复原因；其余情况无需维护错题本或学习日志。
